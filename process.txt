  1. Missing Value Handling
     - Method: Fill with median values

  2. Duplicate Removal
     - Method: drop_duplicates() on full rows and by customer_id
     - Rationale: Remove customer records appearing multiple times
     - Results: 3 duplicate rows removed from Dataset 2
  
  3. Data Type Conversion
     - Convert purchase_date to datetime format
     - Enables proper chronological sorting and date-based analysis
  
  4. Data Standardization
     - Sort data by customer_id and date for consistent ordering
     - Reset index for clean sequential numbering

Data Integration Techniques:

     - Key: customer_id
